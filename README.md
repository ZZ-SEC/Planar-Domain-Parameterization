# Planar-Domain-Parameterization

Implementation of the article "Fast Parameterization of Planar Domains for Isogeometric Analysis via Generalization of Deep Neural Network".

Before running, cpp_accelerate.cpp has to be compiled using pybind11. A compiled version using python 3.9 and VS2019 on windows x64 platform is offered.

Run test.py to parameterize the samples in the test set.
